## G. 已知限制（出现这些现象属预期，不算失败）

- 学号 / 科目编号是固定前缀 + 3 位数字，**超过 999 条会变成 4 位**
- **空姓名、空科目名可以入库**（目前只挡了空学号和空编号）
- 每次保存后 `data/scores.txt` 的**行顺序可能变化**（底层用 `HashMap`，不保证遍历顺序）。数据不丢，只是不利于人肉 diff
- 数据明文存储，没有加密，也没有并发保护
